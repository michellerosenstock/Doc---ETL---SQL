# Doc---ETL---SQL

**Overview**

Building a small ETL and ELT program to transform a messy PDF into an SQL table. 

Working Architecture: 
PDF --> C# Transformation --> CSV file --> Load to SQL Staging Table --> SQL Cleaned Table

Starting small. For now, starting with a single program and a single SQL table in a local PosgreSQL database. This project may expand or change direction based on challenges, opportunities, and feedback.  

Please feel free to check out my project as it unfolds. At this time, I'm open to feedback in the form of GitHub comments on the files I create. I'm building and learning at the same time. I'm curious to hear your thoughts on new features, improved code quality, and code performance optimizations. 

 At some later point, I may change the form in which I'm accepting contributions. I'm experimenting with this project and this form of getting feedback. Thank you for your time, your curiousity, and ideas.
